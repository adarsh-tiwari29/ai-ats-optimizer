# 🚀 AI-Powered ATS Resume Optimizer

A powerful application that leverages Generative AI to analyze and optimize resumes against job descriptions. 

🔴 **Live Demo:** [Click here to view the live project on AWS](http://43.205.253.214:8501)

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Backend:** FastAPI, Python
* **AI Engine:** Google Gemini AI
* **DevOps & Cloud:** Docker, Docker Compose, AWS EC2

## ⚡ Key Features
* Real-time Resume vs Job Description matching.
* AI-driven recommendations for missing keywords.
* Containerized architecture using Docker for seamless deployment.

## ⚙️ Local Setup
1. Clone the repository.
2. Add your `.env` file with `GEMINI_API_KEY`.
3. Run `docker compose up --build -d`.
